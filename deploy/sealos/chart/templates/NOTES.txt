   - Bots → your bot → Channels → connect Discord / Telegram / Slack / QQ / LINE

   {{ $public }}/webhook/line/{{ .Values.lineBotId | default "mochi" }}

   {{ if .Values.persistence.enabled }}{{ default (printf "%s-data" .Release.Name) .Values.persistence.existingClaim }}{{ else }}(no persistence enabled — data is lost on restart){{ end }}
